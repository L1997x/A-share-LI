# A-share-LI

手机可打开的 A 股主板 Serenity 风格观察池应用。

项目采用“静态网页 + GitHub Actions 定时生成数据”的结构，不需要你的电脑长期运行后端服务。推送到 GitHub Pages 后，手机可以直接访问网页。

## 当前功能

- 只观察 A 股主板可买范围：`000/001/002/003/600/601/603/605`
- 每个交易日按 10:00、11:20、13:30、14:30、20:00 五个时段自动刷新数据
- GitHub Actions 自动生成最新股票池和回访数据
- 网页打开并保持前台时，每 2 分钟自动检查一次最新快照；从后台切回页面或网络恢复时会立即检查
- GitHub 定时任务使用主时点 + 备用时点刷新，并按计划触发时段标记数据，避免 GitHub 延迟执行时把 14:30 风控池误判成 20:00 关注池
- 网页展示：
  - 综合评分
  - 可买入信号
  - 可买入价格 / 下一触发价
  - 推荐接入价
  - 突破确认价
  - 不追高线
  - 主力资金流确认
  - 全市场资金热度：换手活跃度、主力净流入扩散和成交集中度
  - 全球市场影响：A50、恒生、日经、美股指数/期货及人民币汇率
  - 筹码结构
  - 上涨趋势过滤：现价 > MA20 > MA60，MA20 近 5 日上行，MA60 近 10 日不明显下行
  - 回访收益与模型反馈
  - 产业链逻辑、催化剂、风险
- 回访中心保留历史推荐，即使股票被调出观察池也继续跟踪收益率
- 模拟交易模块：
  - 初始资金 100000 元
  - GitHub Actions 每次生成数据快照时同步执行云端模拟买入/卖出，手机和电脑关闭后也会继续运行
  - 网页默认只展示自动策略结果，不要求手动操作模拟买卖
  - 自动策略按离散快照执行：08:50先复核隔夜外盘，10:00、11:20、13:30复检买入并预警卖出，14:30先执行卖出/风控，20点生成次日计划，23:10再次复核欧美市场；08:50和23:10只更新计划，不按A股旧收盘价成交
  - 只有交易日09:30-11:30和13:00-15:00生成完成的快照允许模拟成交；延迟到收盘后的任务只更新计划，避免按旧收盘价制造假成交
  - 买入计划分为正式可执行、5%风险试探、10%小仓试买和普通观察；普通观察不会因价格碰线就自动成交
  - 历史接入风险偏高但硬拦截证据不足时，仅允许5%风险试探；下降趋势、失效价或极端市场风险仍禁止买入
  - 偏暖市场中，评分不低于 8.8、资金流和风控通过的标的，可在原接入上限上增加最多 1.5 ATR 的缓冲并以最高 10% 仓位试买
  - 价格低于 MA20 的 97% 时等待止跌，试买价格高于 MA20 的 105% 时避免追涨；仍不允许超过不追高线
  - 卖出按每个快照检查：跌破硬止损、触发止盈、移动回撤、模型评分降级或持仓超过 10 个交易日都会进入风控判断
  - 决策复盘记录每次生成计划、取消买入、执行买入、卖出预警和执行卖出，便于后续检查价格纪律是否有效
  - 以 100 股整数手模拟买入/卖出，并遵守 T+1 可卖数量
  - 买入扣佣金和过户费，卖出扣佣金、印花税和过户费
  - 默认费用：佣金 0.03%、最低 5 元，卖出印花税 0.05%，过户费 0.001%
  - 自动用最新观察池和回访中心价格重估持仓净值和收益
  - 只有满足上涨趋势门槛的股票才会生成或执行模拟买入计划；反弹修复、震荡走弱和下降趋势只保留研究观察
  - 每笔卖出独立跟踪卖出后第 3、5、20、30 个交易日表现；同一股票重新入池或再次买入不会重置旧卖出样本
  - 同类退出至少积累 3 笔成熟样本后，才小幅反馈调整止损、止盈、评分退出或最长持有期参数
  - 账面收益只扣已经发生的买入/卖出费用；清仓后收益会额外扣除预计卖出费用
  - 持仓、计划、成交和决策记录保存在 `data/simulation.json`，所有设备看到同一套结果

自动模拟交易随云端数据任务执行，不依赖网页是否打开。网页只负责读取并展示最近一次云端快照；08:50和23:10只复核盘前/隔夜计划，交易时段按10:00、11:20、13:30、14:30快照复检买卖，20:00生成次日关注计划，并非实时逐笔撮合。

自动数据更新由 GitHub Actions 负责，与你的电脑是否开机无关；但 GitHub 的 `schedule` 是尽力触发，可能延迟或偶发漏跑。本项目增加了备用时点，并把每次计划触发的 cron 传给模型，用计划时段而不是实际执行完成时间来判定 `10点早盘接入` / `14:30尾盘风控` / `20点次日关注` 等阶段。

## 本地运行

直接打开 `index.html` 可以查看静态页面。若浏览器限制本地 `fetch`，可启动一个简单服务：

```powershell
python -m http.server 5173
```

然后访问：

```text
http://127.0.0.1:5173
```

## 手动生成数据

需要 Python 3.10+。GitHub Actions 默认使用 Python 3.11；如果在本地手动运行，请不要使用过旧的系统 Python。

```powershell
python -m pip install -r requirements.txt
python scripts/generate_pool.py
```

数据会写入：

- `data/latest.json`
- `data/review.json`
- `data/universe_scan.json`
- `data/simulation.json`
- `data/history/YYYY-MM-DD.json`
- `data/history/snapshots/YYYY-MM-DDTHHMMSS+0800.json`

其中 `data/history/YYYY-MM-DD.json` 保存当天最新快照，`data/history/snapshots/` 保存最近一段时间的分时生成快照，用于区分 08:50、10:00、11:20、13:30、14:30、20:00、23:10 不同更新时段的回访和模型反馈。

## GitHub Pages 部署

推送到 GitHub 后，进入仓库：

1. 打开 `Settings`
2. 进入 `Pages`
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`
5. Folder 选择 `/(root)`
6. 点击 `Save`

部署完成后，手机打开 Pages 给出的地址即可。

## 重要提示

本项目输出是研究观察、交易纪律辅助和模拟交易记录，不构成确定买卖建议，也不会自动下单。A 股数据源、网页抓取和免费接口都可能出现延迟、缺失或限流；真实交易前需要结合实时行情、公告、财报、交易费用和个人风险承受能力复核。
